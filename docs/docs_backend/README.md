## Règle
Chaque tâche terminée est documentée dans le journal de son auteur **avant** la revue croisée, avec la structure suivante :

```markdown
### <ID> — <Titre>
- **Date** :
- **Branche / commit** :
- **Ce qui a été fait** :
- **Fichiers modifiés** :
- **Décisions techniques** :
- **Comment tester** : (commande, curl, ou lien Swagger)
- **Points d'attention / limites** :
```
